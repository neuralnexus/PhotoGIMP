# PhotoGIMP: Hebrew documentation

The detailed translation has been temporarily retired because it described the
legacy manual workflow and contradicted the current installer's safety contract.

- The current release supports **GIMP 3.0.x only**.
- GIMP 2.x, GIMP 3.2+, Snap, and Portable GIMP are unsupported.
- Older ZIP assets are not equivalent to the manifest-verified installer bundle.
- Do not copy the complete profile without reviewing generated state files.

Use the [main README](../README.md) and
[installer documentation](../installer/README.md) as the authoritative source.
