# PhotoGIMP: documentación en español

Esta traducción detallada se ha retirado temporalmente porque describía el flujo
manual antiguo y contradecía las garantías del instalador actual.

- La versión actual admite únicamente **GIMP 3.0.x**.
- GIMP 2.x, GIMP 3.2 o posterior, Snap y GIMP Portable no son compatibles.
- Los archivos ZIP antiguos no equivalen al paquete verificado por manifiesto.
- No copie el perfil completo sin revisar `filters/`, `plug-in-settings/` y `theme.css`.

Consulte el [README principal](../README.md) y la
[documentación del instalador](../installer/README.md) para las instrucciones y
los límites de seguridad vigentes.
