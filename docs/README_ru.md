# PhotoGIMP: документация на русском

Подробный перевод временно удалён, поскольку он описывал прежний ручной процесс
и противоречил гарантиям текущего установщика.

- Текущий выпуск поддерживает только **GIMP 3.0.x**.
- GIMP 2.x, GIMP 3.2+, Snap и Portable GIMP не поддерживаются.
- Старые ZIP-архивы не являются пакетом, проверяемым по манифесту.
- Не копируйте профиль целиком без проверки созданных файлов состояния.

Актуальные инструкции находятся в [основном README](../README.md) и
[документации установщика](../installer/README.md).
