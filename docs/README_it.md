# PhotoGIMP: documentazione italiana

La traduzione dettagliata è stata temporaneamente ritirata perché descriveva il
vecchio flusso manuale e contraddiceva le garanzie del nuovo installer.

- La versione corrente supporta solo **GIMP 3.0.x**.
- GIMP 2.x, GIMP 3.2+, Snap e GIMP Portable non sono supportati.
- I vecchi archivi ZIP non equivalgono al pacchetto verificato dal manifesto.
- Non copiare l'intero profilo senza controllare i file di stato generati.

Usare il [README principale](../README.md) e la
[documentazione dell'installer](../installer/README.md) come fonte autorevole.
