# PhotoGIMP: 한국어 문서

기존 상세 번역은 오래된 수동 설치 절차를 설명하여 현재 설치 프로그램의
안전 계약과 충돌하므로 임시로 폐기했습니다.

- 현재 릴리스는 **GIMP 3.0.x만** 지원합니다.
- GIMP 2.x, GIMP 3.2 이상, Snap 및 Portable GIMP는 지원하지 않습니다.
- 이전 ZIP 파일은 매니페스트로 검증된 설치 프로그램 번들과 다릅니다.
- 생성된 상태 파일을 검토하지 않고 전체 프로필을 복사하지 마세요.

최신 지침은 [기본 README](../README.md)와
[설치 프로그램 문서](../installer/README.md)를 참조하세요.
