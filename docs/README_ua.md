# PhotoGIMP: документація українською

Докладний переклад тимчасово вилучено, оскільки він описував застарілий ручний
процес і суперечив гарантіям поточного інсталятора.

- Поточний випуск підтримує лише **GIMP 3.0.x**.
- GIMP 2.x, GIMP 3.2+, Snap і Portable GIMP не підтримуються.
- Старі ZIP-архіви не є пакетом, перевіреним за маніфестом.
- Не копіюйте весь профіль без перевірки створених файлів стану.

Актуальні інструкції наведено в [основному README](../README.md) та
[документації інсталятора](../installer/README.md).
