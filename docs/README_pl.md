# PhotoGIMP: dokumentacja polska

Szczegółowe tłumaczenie zostało tymczasowo wycofane, ponieważ opisywało stary
proces ręczny i było sprzeczne z gwarancjami obecnego instalatora.

- Bieżące wydanie obsługuje wyłącznie **GIMP 3.0.x**.
- GIMP 2.x, GIMP 3.2+, Snap i GIMP Portable nie są obsługiwane.
- Starsze pliki ZIP nie są pakietem weryfikowanym przez manifest.
- Nie kopiuj całego profilu bez sprawdzenia wygenerowanych plików stanu.

Aktualne instrukcje zawierają [główny README](../README.md) i
[dokumentacja instalatora](../installer/README.md).
